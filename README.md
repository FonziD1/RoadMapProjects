# Basic HTML Website Project

## Project Overview
This project focuses on structuring a website using **only HTML**—no CSS or styling yet! You'll create multiple pages with semantic HTML, a navigation bar, and SEO meta tags.

## Project URL
🔗 [Basic HTML Website](https://roadmap.sh/projects/basic-html-website)

## Features
- 🏠 Homepage with an introduction
- 📂 Projects page showcasing work
- 📄 Articles page with content
- 📬 Contact page with a form (name, email, message)
- 📍 Navigation bar across all pages
